# How to see the CV preview in Cursor

So you can point at what to edit, open the preview **inside Cursor** using one of these:

---

## Option 1: Simple Browser (built into Cursor)

1. Open **Command Palette**: `Cmd + Shift + P` (Mac) or `Ctrl + Shift + P` (Windows).
2. Type: **Simple Browser: Show**
3. Choose it and press Enter.
4. When it asks for a URL, paste this (use your actual path if different):
   ```
   file:///Users/UCAIEBE/beatrice-portfolio/CV_preview.html
   ```
5. Press Enter. The CV opens in a browser panel **inside Cursor** next to your code.

You can split the editor: have `CV_preview.html` (or your `.tex` file) on one side and the Simple Browser preview on the other, then tell me what to change by section or line.

---

## Option 2: Live Preview extension (best for editing)

1. Install the **Live Preview** extension:  
   Extensions panel (`Cmd + Shift + X`) → search **Live Preview** → Install (by Microsoft).
2. Open **CV_preview.html** in the editor (click it in the file tree).
3. Right‑click inside the editor → **Show Preview**,  
   or click the **Show Preview** icon (split/browser icon) in the top‑right of the editor.
4. The preview opens in a side panel and **updates as you edit** the HTML.

Then you can point to the exact part on the preview and we can edit the same place in the file.

---

## Option 3: Open in your system browser

1. In the file tree, **right‑click** `CV_preview.html`.
2. Choose **Reveal in Finder** (Mac) or **Reveal in File Explorer** (Windows).
3. **Double‑click** the file to open it in Chrome/Safari/Edge.

You’ll see the CV in a separate window. You can describe what to change (e.g. “the Summary paragraph” or “the first bullet under Mondly”), and I’ll apply it to the HTML and, if you want, to the `.tex` file too.

---

**Tip:** For pointing at what to edit, Option 1 or 2 is best so the preview and code are in the same window.
